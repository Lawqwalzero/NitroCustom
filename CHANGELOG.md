# Changelog

## 0.1.0-beta.1

First public beta. Verified on Acer Nitro ANV16S-41, BIOS V1.12, Windows 11.

— Thermal profiles: Eco, Quiet, Balanced, Performance, Turbo. The saved profile is applied at boot and after sleep.

— Live sensors: CPU and GPU temperature, fan speed, CPU load, memory.

— Keyboard lighting: static colour and effects, brightness, speed, direction, per-profile mode-key colour.

— Nitro key opens the window, the mode key cycles profiles, and a small on-screen card shows the new profile.

— Tray app, Windows service and a light session agent. Inno Setup installer, self-contained.

— Command-line tool `nitroctl` for diagnostics.

— Interface and installer in Russian or English, chosen by the Windows display language.

Known limits: no fan curves, one verified model, unsigned installer.
